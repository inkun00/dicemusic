# Dice & Melody · 주사위 음악 작업실

원본의 `I → IV → I → V → I → IV → V → I` 화음 진행과 18개 가락을 바탕으로 만든 오프라인 음악 앱입니다.

## 실행

- **주사위작곡.html**을 Chrome 또는 Edge에서 열면 바로 실행됩니다. 라이브러리와 이미지가 포함된 한 파일이며 인터넷 연결이 필요 없습니다.
- 개발용으로는 `npm start`를 실행하고 표시되는 로컬 주소를 여세요. 사용 가능한 포트를 자동 선택합니다.
- 원본 파일은 `reference/original.html`에 보관되어 있습니다.

## GitHub와 Vercel 배포

GitHub 저장소: [inkun00/dicemusic](https://github.com/inkun00/dicemusic)

`npm run build`는 최신 코드로 단일 HTML 파일을 다시 만들고 웹 배포용 `dist/`를 생성합니다. 배포 폴더에는 앱 실행 파일, 필요한 이미지·라이브러리와 라이선스, 오프라인 다운로드용 `주사위작곡.html`만 포함됩니다. 검증용 `output/`, 원본 `reference/`, 테스트와 개발 스크립트는 웹에 공개되지 않습니다.

Vercel에서 위 GitHub 저장소를 가져오면 `vercel.json`의 정적 사이트 설정이 적용됩니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다. 서버나 별도 환경변수는 필요 없습니다. 이후 연결된 브랜치에 변경을 푸시하면 Vercel이 다시 배포합니다.

Vercel CLI를 사용할 때는 프로젝트 루트에서 `vercel`로 프로젝트를 연결하고 `vercel --prod`로 운영 배포합니다. 오프라인 파일은 배포 주소 뒤에 `/주사위작곡.html`을 붙여 열거나 저장할 수 있습니다.

## 사용

1. 2/4, 3/4, 4/4, 6/8박자를 선택하고 음색과 빠르기를 조절합니다.
2. 마디를 선택하고 주사위를 굴립니다. 각 눈금과 화음마다 48개 가락 후보가 있으며 같은 눈금에서도 직전 가락을 피합니다.
3. 마음에 드는 마디의 마름모 잠금 버튼을 누르면 전체 새로 만들기에서도 그 마디와 가사가 유지됩니다.
4. 7마디는 끝맺음을 준비하고 8마디는 긴 도 음으로 끝납니다.
5. **노래 만들기**를 누르면 8마디 악보 팝업이 열립니다. 음표 아래에 가사를 입력합니다. 한 음표에 1음절을 권장하며 최대 4글자를 입력할 수 있습니다. 쉼표에는 가사 칸이 없습니다. 빈칸은 허용합니다.
   **가락 듣기**를 누르면 현재 연주되는 음표와 가사 칸이 함께 강조됩니다. 악보는 현재 마디를 따라 스크롤하며, 정지하거나 연주가 끝나면 강조가 사라집니다.
6. **악보 만들기**를 눌러 제목과 작곡가를 입력하고 **PDF 악보 저장하기**를 누릅니다.
7. **음악 파일 만들기**는 선택한 음색·빠르기·음량의 멜로디와 반주를 1280 × 720 MP4 영상으로 만듭니다. 검은 화면 가운데 흰색으로 현재 마디의 가사를 보여 주고, 연주되는 음절에 밑줄을 표시합니다. 제작 진행창에서 취소할 수 있으며 완성 창에서 영상을 재생하고 저장합니다.

6/8 BPM은 점4분음표 기준입니다. MP4는 기악 연주와 가사 영상을 담으며 입력한 가사를 노래하는 음성 합성은 포함하지 않습니다. 가사가 없는 마디는 검은 화면으로 표시됩니다. 영상 제작은 곡 길이만큼 걸리며 최신 Chrome 또는 Edge의 H.264/AAC MP4 녹화 기능을 사용합니다. PDF 악보는 한글 글꼴 호환을 위해 고해상도 이미지로 A4 한 페이지에 담습니다. 확대·인쇄에 적합하지만 PDF 내부의 가사 텍스트 검색·편집은 지원하지 않습니다.

곡과 가사는 브라우저 저장 공간에 자동 보관됩니다. 박자를 바꾸거나 해당 마디를 다시 만들면 새 가락의 가사는 비워집니다. **처음부터** 직후 **되돌리기**로 곡을 복구할 수 있습니다. 브라우저나 실행 주소를 바꾸면 저장 공간이 달라집니다.

## 이미지와 UI

참고: [Nomadic Tribe — makemepulse](https://2019.makemepulse.com/). 종이 질감, 잉크 선, 민트·청록·산호색 풍경의 분위기를 분석해 새로운 음악 풍경 일러스트와 UI 종이 소재를 만들었습니다.

- `assets/melody-landscape.png`: built-in image_gen으로 생성한 풍경
- `assets/paper-atlas.png`: built-in image_gen으로 생성한 4색 종이 소재. 버튼, 카드, 박자·음색 선택, 재생 컨트롤에 공통 적용
- `assets/imagegen-prompts.json`: 사용한 전체 프롬프트

글자와 악보·조작 컨트롤은 실제 DOM/SVG로 동작하므로 모바일, 키보드, 스크린리더를 지원합니다.

높은음자리표는 [Steinberg Bravura](https://github.com/steinbergmedia/bravura)의 `gClef` (U+E050) 자형을 추출한 `assets/treble-clef.svg`를 사용합니다. 앱 화면과 PDF 악보에 같은 이미지를 포함하며 별도 글꼴 설치나 인터넷 연결이 필요 없습니다. 원본 글꼴, SIL Open Font License, 출처 기록은 `vendor/bravura-*`에 보관하고 라이선스 원문도 단일 HTML 파일에 포함합니다.

## 개발·검증

`npm test`: 음악 생성, 박자 길이, 재생 시점, 음표·가사 좌표, 종지, 입력 이스케이프에 대한 검사를 실행합니다.

`node build-standalone.cjs`: 변경된 코드와 이미지로 단일 HTML 배포본을 다시 생성합니다.

PDF 라이브러리는 로컬 `vendor/`에 포함되어 있습니다. 개발 의존성을 다시 받으려면 `npm ci --ignore-scripts`를 사용하세요. jsPDF는 MIT이며 라이선스 원문을 `vendor/`에 보관했습니다. MP4는 브라우저의 MediaRecorder로 생성하며 영상이나 가사를 외부 서비스에 보내지 않습니다.
